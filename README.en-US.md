

# 2026 Emerging Journal Partition Quick Query Tool

> Based on the [XR-Scholar](https://www.xr-scholar.com/) 2026 Emerging Journal Partition Table, this tool provides quick query assistance for broad discipline partitions.

## Online Usage

👉 **https://aarongig.github.io/xr-journal-query/**

No installation required; open and use directly. You can also download the `index.html` file locally and open it in a browser with a double-click for offline use.

## Features

- Covers **21 broad disciplines** and **22,301 journals**
- Instant search by journal name with real-time filtering of results
- Filter by broad discipline, partition (Quartile 1-4), and Top journals
- Each result links to the XR-Scholar official website for detailed information
- Single HTML file, approximately 1MB, supports offline use
- Mobile browser compatible

## Data Description

- **Data Source**: [XR-Scholar Emerging Journal Partition Table](https://www.xr-scholar.com/Category/ZKY)
- **Data Year**: 2026
- **Coverage Scope**: Broad discipline partitions (21 discipline categories)
- **Displayed Fields**: Journal name, broad discipline, partition (Quartile 1-4), Top status
- For detailed information such as sub-discipline partitions (JCR partitions), ISSN, EISSN, impact factor, etc., please visit the [XR-Scholar official website](https://www.xr-scholar.com/).
